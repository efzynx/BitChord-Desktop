Engineered for Perfection

Modern aesthetics harmonized with desktop-grade performance

Native FFmpeg 7.1 Pipeline

Integrated JavaCPP hardware-accelerated audio pipeline supporting lossless Hi-Res streaming (FLAC, ALAC, WAV) and standard Opus/AAC playback with 32-bit float internal precision.

Listen Together (Party Mode)

Listen synchronously with friends worldwide. Instant connection via built-in cloud server, self-hosted VPS, or local one-click Cloudflare Quick Tunnel.

Synchronized Lyrics & Motion Art

Real-time word-by-word synced lyrics accompanied by Apple Music motion canvas banners decoded smoothly at low CPU consumption.

Native OS Media Integration

Full MPRIS D-Bus support on Linux (GNOME, KDE Plasma, playerctl) and Windows System Media Transport Controls (SMTC) in volume overlay and lock screen.

Zero-Configuration Discord RPC

Direct local Inter-Process Communication (IPC) via Unix Domain Sockets on Linux and Named Pipes on Windows without third-party bots or bot tokens.

DJ Automix & Seamless Transitions

Tempo and beat-matched song transitions powered by Aubio and ONNX neural analysis models for uninterrupted musical flow.

An independent, community-driven desktop port of BitChord by Kushagra Singh. Reconstructed, modernized, and maintained by efzynx with AI engineering assistance from Google DeepMind Gemini.
