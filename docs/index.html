Didesain untuk dengar.

Harmonisasi estetika modern bergaya Apple Music dengan performa audio kelas desktop.

Antarmuka Apple Music & Frosted Glass

Lapisan liquid glass tembus pandang, ekstraksi palet warna dinamis dari sampul album, scrubber interaktif dengan time preview, dan teks marquee berjalan otomatis.

Mesin Audio Native FFmpeg 7.1

Pipeline decoding JavaCPP terakselerasi perangkat keras dengan presisi internal 32-bit float. Mendukung format Hi-Res Lossless (FLAC, ALAC, WAV) dan Opus/AAC.

Listen Together (Mode Pesta)

Dengarkan musik bersama teman secara sinkron. Dukungan instan server cloud bawaan, VPS kustom, atau Quick Tunnel Cloudflare lokal satu klik tanpa port forwarding.

Lirik Tersinkronisasi & Artwork Bergerak

Tampilan lirik kata per kata yang akurat (LRCLIB, Musixmatch, YouTube) disertai animasi Apple Music motion canvas banner yang dirender hemat CPU.

Integrasi Media OS & Discord RPC

Dukungan penuh Linux MPRIS D-Bus dan Windows SMTC (volume overlay & lock screen), serta Discord Rich Presence lokal melalui IPC tanpa bot token.

DJ Automix & Pustaka Lokal

Transisi antarlagu yang mulus dengan analisis tempo dan ketukan bertenaga Aubio & ONNX, serta monitoring direktori lagu lokal real-time.

Cara instal

Ikuti langkah sesuai sistem operasimu. Siap digunakan dalam hitungan detik.

Linux

Universal AppImage (Direkomendasikan): Beri izin eksekusi lalu jalankan langsung:
chmod +x BitChord-*-x86_64.AppImage && ./BitChord-*-x86_64.AppImage

Debian / Ubuntu / Mint (.deb): Pasang paket native melalui terminal:
sudo apt install ./bitchord_*_amd64.deb atau sudo dpkg -i bitchord_*_amd64.deb

Fedora / RHEL / openSUSE (.rpm): Pasang paket RPM:
sudo dnf install ./bitchord-*.x86_64.rpm

Portable Tar.gz: Ekstrak arsip lalu jalankan skrip integrasi:
./BitChord/bin/BitChord atau daftarkan launcher desktop via ./scripts/install-desktop.sh

Windows

Setup Installer EXE (Direkomendasikan): Jalankan BitChord-*.exe untuk memasang aplikasi dengan pintasan Start Menu dan Desktop otomatis. Runtime Java sudah terintegrasi penuh.

Windows MSI Installer: Jalankan BitChord-*.msi untuk pemasangan sistem berbasis Windows Installer standar.

Portable ZIP: Ekstrak arsip ZIP di lokasi mana pun, lalu klik dua kali BitChord.vbs untuk menjalankan pemutar secara instan di latar belakang tanpa jendela terminal.
